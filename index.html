🔑 Jeton GitHub

Pour que l'arbre soit partagé (ajouté au dépôt par une demande signée depuis ce navigateur), il faut un jeton d'accès GitHub. Il reste stocké uniquement dans ce navigateur et n'est jamais envoyé ailleurs qu'à l'API GitHub.

Crée-le sur github.com/settings/personal-access-tokens/new : Repository access → Only select repositories → olivemap, puis Permissions → Contents → Read and write.
